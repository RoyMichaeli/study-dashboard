# 📚 דשבורד לימודים חכם

דשבורד מתקדם לניהול למידה עבור סטודנטים, בנוי עם React + TypeScript + Tailwind CSS.

## ✨ תכונות עיקריות

### 🎯 ניהול קורסים
- **גלריית קורסים** - כרטיסיות אינטראקטיביות עם התקדמות
- **מעקב התקדמות** - חישוב אוטומטי של אחוזי השלמה
- **תאריכי מבחנים** - תזכורות ויזואליות
- **נתונים סטטיסטיים** - גרפים ותרשימים מתקדמים

### 📖 מצבי למידה שונים
1. **סקירה כללית** - מבט מקיף על כל הנושאים
2. **כרטיסי למידה** - מצב חזרה אינטראקטיבי
3. **מבחן עצמי** - (בפיתוח) בדיקת ידע
4. **הערות** - (בפיתוח) מחברת אישית

### ⚡ פיצ'רים אינטראקטיביים
- ✅ **סימון מטרות כהושלמו** - קליק להשלמה/ביטול
- 📝 **הוספת הערות אישיות** - לכל נושא
- 🔄 **drag & drop** - (בפיתוח) סידור מחדש
- 📊 **ויזואליזציות** - גרפי bar ו-pie charts

## 🚀 הפעלה מהירה

```bash
# התקנת dependencies
pnpm install

# הרצת הדשבורד
pnpm run dev

# פתיחה בדפדפן
open http://localhost:5173
```

## 📁 מבנה הפרויקט

```
src/
├── components/          # קומפוננטים שמישים
│   ├── CourseCard.tsx   # כרטיס קורס
│   ├── TopicView.tsx    # תצוגת נושא
│   ├── FlashcardView.tsx # כרטיסי למידה
│   └── ProgressChart.tsx # גרפי התקדמות
├── store/              # ניהול state עם Zustand
│   └── useStore.ts     # store מרכזי
├── data/               # נתוני הדגמה
│   └── sampleCourses.ts # קורסי דוגמה
└── App.tsx             # קומפוננט ראשי
```

## 🛠️ טכנולוגיות

- **React 18** - ממשק משתמש
- **TypeScript** - type safety
- **Tailwind CSS** - עיצוב מהיר
- **Zustand** - ניהול state
- **Recharts** - גרפים וויזואליזציות
- **Lucide React** - אייקונים
- **Framer Motion** - אנימציות (מוכן לשימוש)

## 📚 הוספת הנתונים שלך

### שלב 1: הכנת קובץ JSON
צור קובץ JSON בפורמט הזה:
```json
{
  "מצגת": "שם הקורס",
  "נושאים": [
    {
      "כותרת": "שם הנושא",
      "מטרות": [
        "מטרה 1",
        "מטרה 2"
      ]
    }
  ]
}
```

### שלב 2: טעינת הנתונים
1. שים את הקובץ בתיקיית `src/data/`
2. ייבא אותו ב-`App.tsx`
3. הוסף לרשימת הקורסים

### דוגמה:
```typescript
import { myOrganicChemistry } from './data/myOrganicChemistry'

// ב-useEffect
addCourse({
  id: generateId(),
  ...myOrganicChemistry,
  progress: 0,
  examDate: '01/07/2025'
})
```

## 🎨 התאמה אישית

### צבעים
ערוך את `tailwind.config.js`:
```javascript
theme: {
  extend: {
    colors: {
      primary: {
        500: '#your-color',
        600: '#your-darker-color'
      }
    }
  }
}
```

### הוספת פיצ'רים חדשים
1. צור קומפוננט חדש ב-`components/`
2. הוסף actions חדשים ל-`store/useStore.ts`
3. שלב ב-`App.tsx`
